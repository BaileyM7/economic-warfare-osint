## Deep Analysis (the agent swarm) — pre-warmed queries

The open-ended "Ask Anything" swarm runs ~30–60 live agents; a **novel** question takes
**~6–7 minutes** on stage (decompose ~45s → execute ~3.5m → synthesize ~2.5m). To keep
the demo fast, these four questions are **pre-warmed** and **replay in ~10–20s** with the
full swarm animation. Type or paste one **exactly** (the cache matches the exact text):

```
What happens to global semiconductor supply if we sanction Fujian Jinhua?
```
```
Who ultimately owns Nuctech, and what are its sanctions exposures?
```
```
How exposed is the drone supply chain to a DJI export ban?
```
```
Map Rosatom’s subsidiaries and their Western trade links.
```

- **Exact text → instant replay** (~10–20s). Even one different word → it runs **live** (~6–7 min).
- Note the curly apostrophe in *Rosatom’s* (’ U+2019) — paste, don't retype, to be safe.
- The starter "Try" chips were removed (so the swarm doesn't look pre-programmed); use this sheet instead.
- Pre-warm is a 24h TTL — if the demo is >24h after the last warm, ping to re-warm the morning of.
